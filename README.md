# Multilingual OCR System

## 📌 Overview

This project is a Multilingual Optical Character Recognition (OCR) system built using PaddleOCR and Streamlit. It extracts text from images and PDFs and converts it into readable paragraph format.

## 🚀 Features

* Extract text from images and PDFs
* Supports multiple languages (English, Hindi, Chinese)
* Displays bounding boxes on detected text
* Converts raw OCR output into structured paragraph format
* Simple and interactive UI using Streamlit

## 🛠️ Technologies Used

* Python
* PaddleOCR
* OpenCV
* Streamlit

## ▶️ How to Run

1. Clone the repository:

   ```
   git clone https://github.com/your-username/Multilingual-OCR-System.git
   ```

2. Navigate to the folder:

   ```
   cd Multilingual-OCR-System
   ```

3. Install dependencies:

   ```
   pip install -r requirements.txt
   ```

4. Run the app:

   ```
   streamlit run app.py
   ```

## 📷 Output

The system processes uploaded images or PDFs and displays extracted text in paragraph format instead of raw or tabular form.
